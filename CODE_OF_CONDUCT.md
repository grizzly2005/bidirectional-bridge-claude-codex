# Community conduct

Treat contributors and users with respect. Discuss technical claims using evidence and
constructive feedback. Harassment, discrimination, threats, doxxing, unwanted sexual
attention and deliberate disclosure of private information are not acceptable.

This policy applies to issues, pull requests, reviews and project discussions. Maintainers
may remove abusive content, close disruptive discussions or restrict participation.
Moderation decisions should be proportionate to the conduct and available evidence.

Contact the maintainer using the contact details published on their GitHub profile. If no
private contact is available, open an issue requesting a private channel without including
sensitive information. Keep personal information and private messages out of public reports.
Security reports use the separate [security policy](SECURITY.md).
