# Security policy

This bridge is experimental and pre-1.0. No production security certification or guaranteed
response time is offered. See [the security and privacy guide](docs/security.md) for the
trust boundary and sensitive data handling.

## Supported versions

Security fixes target the latest published checkpoint. Older versions are not maintained.
Read the [release policy](docs/release-policy.md) before upgrading a database.

## Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/grizzly2005/bidirectional-bridge-claude-codex/security/advisories/new)
to report an affected revision, a redacted reproduction and the observed impact. Keep
credentials, prompts, transcripts, runtime handles, trust state and databases out of reports.
Do not publish a working exploit in a public issue.
